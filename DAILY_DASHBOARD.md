# Daily Opportunity Dashboard

> This file is intended to be regenerated every day by the GitHub Actions scout.

## TODAY'S TODO

- [ ] Check the **NEW PROGRAMS** section first.
- [ ] Complete the single highest-priority application/deadline task.
- [ ] Complete one meaningful OSS contribution task.
- [ ] Work on the current GSoC/LFX preparation target.
- [ ] Review deadlines within 30 days.
- [ ] Update application/contribution status after finishing work.

## NEW PROGRAMS

The daily scout will add only genuinely new programs/tracks or materially changed opportunities. Existing records must not be duplicated.

## DEADLINE ALERTS

The daily scout will surface confirmed deadlines within 30 days.

## EARLY-PREP ALERTS

The daily scout will surface opportunities opening approximately 2–3 months from now so preparation can start early.

## OSS / GSoC ACTION

The daily scout will identify concrete contribution actions, maintainer/community actions, issues, PRs, documentation/tests, and proposal-preparation work where supported by current evidence.

## ACCOUNTABILITY

At the end of the day, mark completed tasks and carry unfinished work forward deliberately.
