# Daily Opportunity Scout Rules

## Mission

Maintain the master opportunity register and produce a practical daily action dashboard.

## Non-negotiable rules

1. Never delete existing master records.
2. Distinguish:
   - genuinely new program
   - renamed program
   - duplicate
   - parent/child track
   - recurring program
   - inactive/historical program
   - eligibility-gated program
   - strategy/outreach route
3. Never invent deadlines, eligibility, funding, India eligibility, mentors, projects, or participation history.
4. Prefer official program sources.
5. If a fact is uncertain, label it **UNVERIFIED / WATCH**.
6. For time-sensitive claims, use current web research.
7. Keep the user's B.Tech AI & DS profile and India location in mind when assessing relevance, but do not assume eligibility where the official rules do not establish it.
8. Treat GSoC/LFX preparation as an early-contribution strategy: meaningful issues, tests, bug fixes, documentation, code review, community participation, and project understanding matter more than spammy tiny PRs.
9. Pyodide is not a GSoC target for this plan and should not be promoted as one.
10. Do not give political content or rankings; this repository is a career/opportunity tracker.

## Daily output

Produce these sections:

1. **NEW PROGRAMS** — genuinely new records/tracks only.
2. **CHANGES** — deadline, eligibility, status, application window, or funding changes.
3. **UPCOMING 3 MONTHS** — confirmed or clearly recurring opportunities.
4. **EARLY-PREP ALERTS** — opportunities roughly 2–3 months away.
5. **DEADLINE ALERTS** — confirmed deadlines within 30 days.
6. **TODAY'S TODO** — 3–7 concrete actions, ordered by urgency.
7. **GSoC / OSS ACTION** — one or two concrete contribution actions.
8. **ACCOUNTABILITY** — what should be marked complete today.

Each important current claim should include its source URL in the generated dashboard.
